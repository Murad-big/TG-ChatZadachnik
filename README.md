# Задачник для Telegram

Бот для командного чата: помогает назначать задачи, указывать ответственных и сроки, просматривать список и менять статус выполнения. Задачи хранятся в Excel. Отдельный модуль работает с идеями в Google Таблицах.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Проверить, что бот отвечает |
| `/help` | Посмотреть справку |
| `/set_deadline @username DD/MM/YYYY описание` | Назначить задачу |
| `/check_deadline` | Открыть список задач по участникам |

Для изменения статусов и удаления используются кнопки в сообщениях. Доступ к чату и редактированию задаётся в настройках.

## Подготовка

Нужны Python, токен Telegram-бота и собственная Google Таблица с доступом для сервисного аккаунта.

1. Установите зависимости: `python-telegram-bot[job-queue]`, `APScheduler`, `openpyxl`, `gspread` и `oauth2client`.
2. Создайте локальный `config.py` с параметрами `TOKEN`, `ALLOWED_CHAT_ID`, `ALLOWED_USERNAMES` и `EXCEL_FILE`. Этот файл не включён в репозиторий.
3. Добавьте ключ сервисного аккаунта в локальный `credentials.json`.
4. В `google_sheet_handler.py` укажите свою таблицу и подготовьте листы «Предложенные», «Одобренные» и «На реализацию» с колонками, которые читает модуль.

После настройки точка входа:

```bash
python main.py
```

## Структура

- `handlers.py` — команды, выбор задач и изменение статусов.
- `excel_manager.py` — чтение и запись Excel.
- `google_sheet_handler.py` — перенос идей между листами и уведомления.
- `scheduler.py` — напоминания о сроках.
- `utils.py` — проверки доступа.

Проект требует настройки под конкретный чат и таблицу. Перед использованием в команде проверьте обработчики и фоновые задания на тестовых данных. Токены, ключи и рабочие таблицы не следует добавлять в репозиторий.
